# Менеджер автозапуска GNOME

🌍 **[Türkçe](README.tr.md) | [English](README.md) | Русский | [Български](README.bg.md)**

Современный GTK-менеджер автозапуска GNOME с полноценным **Планировщиком задач** на базе `systemd --user`. Написан полностью на Python — никаких дополнительных зависимостей.

Приложение **автоматически определяет язык системы** и отображается на турецком, английском, русском или болгарском языке.

---

## ✨ Возможности

### Менеджер автозапуска
- **Настоящие иконки** — отображает иконки из `.desktop`-файлов
- **Статус и ресурсы в реальном времени** — CPU (%) и RAM (МБ/ГБ) с отслеживанием PID
- **Множественный выбор** — запуск, остановка или удаление нескольких приложений одновременно
- **Безопасная остановка** — использует PID-файлы; никогда не завершает не тот процесс
- **Терминальный режим** — запуск скриптов в видимом окне GNOME Terminal
- **Задержка запуска** — настройка задержки в секундах для каждого приложения

### Планировщик задач (альтернатива cron)
- **Интервал** — запуск каждые N минут / часов / дней
- **Календарь** — запуск в определённые дни и время (напр. каждый понедельник в 09:00)
- **Загрузка** — при запуске системы (в фоне, без входа в систему при Lingering)
- **Вход** — при открытии сессии
- **Ручной запуск** — кнопка «Запустить сейчас» для немедленного теста
- **Поддержка Lingering** — одним кликом `loginctl enable-linger` из Настроек

### Общее
- **Горячие клавиши** — `Ctrl+N`, `Ctrl+E`, `Ctrl+S`, `Ctrl+K`, `Delete`
- **Системный трей** — работает в фоне с иконкой в трее
- **Память окна** — запоминает размер и положение
- **Многоязычность** — Турецкий 🇹🇷, Английский 🇬🇧, Русский 🇷🇺, Болгарский 🇧🇬

```bash
python3 baslangic-yoneticisi.py
```

**Требования:** Python 3.8+, GTK 3, systemd
