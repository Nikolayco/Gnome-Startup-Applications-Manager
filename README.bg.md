# Мениджър за автостартиране на GNOME

🌍 **[Türkçe](README.tr.md) | [English](README.md) | [Русский](README.ru.md) | Български**

---

> Търсих едно приложение, което едновременно да управлява автостартиращите приложения на GNOME **и** да работи като истински планировщик на задачи — да изпълнява скриптове на зададен интервал, при стартиране на системата или в конкретен час. Не намерих нищо подходящо, затова го разработих сам.

---

Съвременен GTK-мениджър за автостартиране на GNOME с пълноценен **Планировщик на задачи** на база `systemd --user`. Написан изцяло на Python — без допълнителни зависимости.

Приложението **автоматично открива езика на системата** и се показва на турски, английски, руски или български.

---

## ✨ Функции

### Мениджър за автостартиране
- **Истински икони** — показва иконите от `.desktop` файловете
- **Статус и ресурси в реално време** — CPU (%) и RAM (МБ/ГБ) с проследяване на PID
- **Множествен избор** — стартиране, спиране или изтриване на множество приложения наведнъж
- **Безопасно спиране** — използва PID файлове; никога не убива грешен процес
- **Терминален режим** — стартиране на скриптове в видим прозорец на GNOME Terminal
- **Закъснение при стартиране** — конфигуриране на закъснение в секунди за всяко приложение

### Планировщик на задачи (алтернатива на cron)
- **Интервал** — изпълнение на всеки N минути / часове / дни
- **Календар** — изпълнение в определени дни и часове (напр. всеки понеделник в 09:00)
- **Зареждане** — при стартиране на системата (фонов режим без вход при Lingering)
- **Вход** — при отваряне на сесия
- **Ръчно задействане** — бутон „Изпълни сега"
- **Поддръжка на Lingering** — с един клик `loginctl enable-linger` от Настройки

### Общо
- **Системен трей** — работи тихо на заден план
- **Памет на прозореца** — запомня размера и позицията
- **Многоезичност** — Турски 🇹🇷, Английски 🇬🇧, Руски 🇷🇺, Български 🇧🇬

## ⌨️ Клавишни комбинации

| Комбинация | Функция |
|------------|---------|
| `Ctrl + N` | Добави ново приложение за автостартиране |
| `Ctrl + E` | Редактирай избраното приложение |
| `Ctrl + S` | Стартирай избраното приложение |
| `Ctrl + K` | Спри избраното приложение |
| `Delete` | Изтрий избраното приложение |
| `Ctrl + F` | Фокусирай полето за търсене |

## 🚀 Инсталация

```bash
git clone https://github.com/Nikolayco/Gnome-Startup-Applications-Manager.git 2>/dev/null || true
cd Gnome-Startup-Applications-Manager
bash install.sh
```

Командата инсталира приложението в `~/.local/bin` и го добавя автоматично в **мрежата с приложения (App Grid)**.

**Изисквания:** Python 3.8+, GTK 3, systemd

---

## 🗑️ Деинсталиране

```bash
git clone https://github.com/Nikolayco/Gnome-Startup-Applications-Manager.git 2>/dev/null || true
cd Gnome-Startup-Applications-Manager
bash uninstall.sh
```

> **Забележка:** Вашите собствени `.desktop` записи няма да бъдат изтрити — изтриват се само файловете, създадени от това приложение.
